# XX卫生服务中心

面向社区卫生健康服务的微信小程序示例。**当前仓库为「本地演示版」**：不依赖微信云开发即可在微信开发者工具中编译运行；业务数据全部读写本机 `Storage`，用于界面与流程演示，**不能**作为真实医疗业务或公卫系统使用。

---

## 一、演示版说明

| 项目 | 说明 |
|------|------|
| 数据存储 | `wx.setStorageSync` / `wx.getStorageSync`，键名由 `miniprogram/utils/cloudStore.js`、`miniprogram/utils/adminAuth.js` 等模块维护 |
| 云开发 | `app.js` 中已关闭 `wx.cloud.init`，未开通云环境也不会报错 |
| 居民身份 | 通过「我的」页绑定 **11 位大陆手机号** 作为演示身份；「我的预约」、食疗方案查询等会按该手机号过滤 |
| 管理端 | 固定演示账号 `admin` / `admin123`，详见 **3.3**、**4.1**；会话标记存于本机 |
| 与正式版的差异 | 无真实服务端鉴权、无多端同步、清除缓存或换设备后数据丢失；内容均为健康教育演示文案 |

后续若接入微信云开发，可在保持页面与对外接口不变的前提下，替换 `cloudStore.js`、`adminCloud.js` 的实现，并恢复 `app.js` 中的云初始化逻辑。

---

## 二、环境与运行

1. 安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)（稳定版即可）。
2. 打开工具，选择 **导入项目**，项目目录选本仓库根目录（包含 `project.config.json` 与 `miniprogram/` 的那一层）。
3. **AppID**：可使用测试号，或填入你已注册的小程序 AppID；演示版不强制开通云开发。
4. 点击 **编译**。底部 Tab 应出现：首页、服务、预约、宣教、我的。

若编译报错，请确认 `miniprogramRoot` 为 `miniprogram/`（已在 `project.config.json` 中配置）。

## 三、居民端使用指南

### 3.1 底部 Tab 功能概览

- **首页**：中心简介、通知列表、快捷入口；可进入公告详情。
- **服务**：服务项目列表；进入详情后可 **立即预约**（会带上服务类型等信息跳转到预约 Tab）。
- **预约**：填写姓名、手机号、日期及服务类型等提交预约；数据写入本地列表。手机号需符合大陆 11 位规则（以 `1[3-9]` 开头）。
- **宣教**：健康宣教文章列表与详情；文章数据可由管理端维护或来自演示种子。
- **我的**：展示/修改绑定手机号、入口菜单（我的预约、意见反馈、食疗方案、健康档案等）。

### 3.2 绑定手机号（建议先做）

在 **我的** 中绑定手机号后，**我的预约** 仅展示与该手机号关联的预约记录；**食疗方案** 查询、**健康档案** 等也与该身份关联。未绑定时部分页面会提示先绑定。

## 四、管理端使用指南

### 4.1 登录账号

| 字段 | 演示值 |
|------|--------|
| 用户名 | `admin` |
| 密码 | `admin123` |

（居民端演示用手机号见 **3.3**，与后台账号无关。）

账号密码写死在 `miniprogram/pages/admin/login/login.js`；若你本地修改了源码，以文件内 `FIXED_USER` / `FIXED_PASS` 为准。

登录成功后进入 **控制台（总览）**；会话依赖本机 Storage，**清空全部缓存** 后需重新登录。

### 4.2 控制台常用操作

在总览中通常可进行：

- **初始化演示数据**：在本地为空或部分缺失时填充演示用的科室、医生、文章、预约等（具体行为以控制台按钮说明为准）。
- **清空本地数据**：清除业务类 Storage 键；一般 **不会** 清除管理员登录标记（便于继续操作后台）。
- **重新初始化**：先清空再全量写入种子数据。

若写入 Storage 失败（空间不足等），界面会提示「本地存储失败，请清理缓存后重试」类文案。

### 4.3 管理端子模块（从控制台进入）

包括但不限于：预约记录、公卫演示档案、居民自填档案列表与详情、宣教文章编辑、宣教主题与顶栏图、菜谱与食疗方案维护、科室与医生、诊所元数据、数据导出中心等。均为 **本地数据** 的增删改查与导出演示。

## 五、数据与调试建议

- **仅本机有效**：换模拟器、真机或清除存储后，数据需重新初始化或重新录入。
- **快速恢复演示**：管理端执行「初始化演示数据」或「重新初始化」。
- **回归测试**：仓库内 `TEST_CHECKLIST.md` 提供居民端、管理端、权限与边界的手工检查清单，可与当前行为对照验收。
